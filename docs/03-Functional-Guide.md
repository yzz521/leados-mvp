# 03 — 功能说明与操作手册

## 1. 总览工作台

总览页展示：

- 全部线索数量。
- 新线索数量。
- 高意向线索数量（当前规则评分 >= 75）。
- 未完成任务数量。
- 新线索、已筛选、跟进中、商机、已成交阶段的漏斗。
- 最近新增线索及近期跟进任务。

顶部业务线筛选可切换“全部业务 / 本地获客 / 外贸开发”。

## 2. 线索中心

### 新增线索

至少填写企业名称或联系人姓名之一。其他字段包括：

- 业务线：`LOCAL` 或 `EXPORT`。
- 主体类型：`COMPANY` 或 `PERSON`。
- 企业名称、联系人、邮箱、电话。
- 地区/国家、线索来源、意向产品、需求。
- 预算、预计决策时间、负责人。
- 联系权限：`UNCONFIRMED`、`AUTHORIZED`、`OPTED_OUT`、`NOT_APPLICABLE`。

如果同一业务线内邮箱或电话号码已存在，API 返回 HTTP 409，前端提示重复线索。当前去重逻辑是 MVP 规则，不等于实体解析或企业合并算法。

### 阶段管理

| 状态 | 含义 |
|---|---|
| NEW | 新线索 |
| QUALIFIED | 已完成初步筛选 |
| CONTACTED | 已开始跟进 |
| OPPORTUNITY | 已形成销售商机 |
| WON | 已成交 |
| LOST | 已丢单 |

阶段变更会创建一条系统互动记录。正式系统还应记录操作者、变更前后值和原因。

### 详情与互动

线索详情展示客户字段、评分、评分说明和互动历史。备注是人工记录，不会向外发送消息。

### 删除

当前 API 提供硬删除，仅供本地演示。正式产品建议使用软删除/数据生命周期管理，并满足保留义务、删除请求和审计需要。

## 3. 客户分析

当前使用本地规则计算 0–100 分：

| 维度 | 分值 |
|---|---:|
| 有明确需求描述 | 25 |
| 已明确意向产品 | 15 |
| 已填写预算 | 15 |
| 已填写决策/采购时间 | 15 |
| 有邮箱 | 10 |
| 有电话 | 10 |
| 有地区/国家 | 5 |
| 有来源 | 5 |

分级：高意向 >= 75；中意向 45–74；低意向 < 45。

该模型只用于演示，不能理解为真实成交概率。它会将信息完整度近似映射成优先级。真实 AI 版本应先定义业务标签和评估集，再判断产品匹配度、需求明确度、采购角色、采购时机等。

对 `OPTED_OUT` 客户，建议文本明确提示不得营销触达。

## 4. 跟进任务

任务支持：

- 标题、说明。
- 可选关联线索。
- 优先级：低、普通、高。
- 截止时间。
- 状态：待处理、进行中、已完成。

当前页面的圆形按钮用于完成/重新打开任务。正式版需要补上任务负责人、提醒渠道、重复任务和 SLA。

## 5. CSV 导入

选择“导入 CSV”，上传 UTF-8 CSV 文件。模板见 `examples/`。

支持字段（中文或英文）：

- `marketType` / 市场类型 / 业务线
- `subjectType` / 主体类型
- `companyName` / 企业名称 / 公司名称
- `contactName` / 联系人 / 姓名
- `email` / 邮箱
- `phone` / 电话 / 手机号
- `region` / 地区 / 城市 / 国家
- `source` / 来源
- `productInterest` / 意向产品 / 产品
- `requirement` / 需求
- `budget` / 预算
- `timeline` / 采购时间 / 预计时间
- `owner` / 负责人
- `contactPermission` / 联系授权

若没有市场类型列，则使用当前业务线作为默认值。导入结果包含新增数、重复数、无效数以及最多 10 条错误说明。CSV 需要使用 UTF-8 编码；Excel 导出时建议选 UTF-8 CSV。

## 6. Local 与 Export 的区别

Local：region 通常记录城市/区域，source 通常记录官网表单、二维码、门店、人工录入等。

Export：region 通常记录国家/地区，source 记录客户自有名单、企业官网、经授权的数据供应商、展会等。

两类线索当前字段结构相同。正式版应按市场增加专属字段，但要避免在共同表中无限增加大量 nullable 字段；可采用 extension 表或结构化属性字段，并保证字段定义与查询策略可控。
