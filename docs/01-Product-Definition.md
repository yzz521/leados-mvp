# 01 — 产品定义与 MVP 范围

## 1. 产品定位

LeadOS 是面向中小企业的 AI 商机增长工作台，围绕线索、客户、销售跟进和转化提供统一操作入口。

产品目标不是“采集尽可能多的联系方式”，而是把**有合法来源的潜在客户信息**转变成可分配、可分析、可跟进、可衡量的销售机会。

## 2. 目标市场

### Local Growth

面向国内本地商家和小型销售团队，优先考虑装修、门窗、全屋定制、建材、汽车服务、婚庆摄影、企业服务等需要咨询、报价、预约和多轮跟进的业务。

初期入口：客户自愿提交的 H5 表单、官网表单、二维码表单、人工录入、客户授权提供的 CSV/API 数据。平台账号连接要通过官方接口或平台授权服务。

### Export Growth

面向外贸工厂、贸易公司及 B2B 出口团队。业务流程为目标市场定义、企业发现、企业研究、联系人核验、个性化开发内容、销售跟进和商机管理。

初期数据源：客户自有客户名单、企业官网公开的企业级业务信息、获得商业使用许可的数据供应商。不得把未经授权抓取作为核心数据能力。

## 3. 产品共同点与差异点

共同底座：租户、用户、企业、联系人、线索、商机、互动、任务、工作流、AI 调用、订阅用量、审计。

Local 特有：地区、门店/服务范围、预约、咨询需求、到店/量房等转化事件、国内渠道连接器。

Export 特有：国家、行业、企业匹配度、采购角色、来源/验证状态、邮件开发与回复状态、国家地区规则配置。

底层共用客户和销售对象，但流程、字段、数据来源、触达许可与渠道连接器必须按业务线扩展。

## 4. MVP 用户角色

当前本地版本只有演示工作空间，不实现真实用户系统。正式 SaaS 建议具备：

- 租户 Owner：企业套餐、成员、权限和账单。
- 管理员：业务配置、渠道、数据导入、团队分配。
- 销售：客户、线索、商机、任务和沟通记录。
- 只读分析员：报表和漏斗。

## 5. MVP 功能

| 功能 | 当前版本实现 | 验收结果 |
|---|---|---|
| 总览 | KPI、阶段漏斗、最近线索、待办 | 页面显示持久化数据 |
| 线索管理 | 新增、搜索、筛选、阶段修改、删除 | API 和 UI 可用 |
| CSV 导入 | 中文/英文列名、重复跳过、错误计数 | 可导入示例模板 |
| 客户详情 | 基础字段、互动记录、备注 | 能查看和添加备注 |
| 客户评分 | 规则评分和解释 | 返回 0–100 分及建议 |
| 跟进任务 | 创建、关联线索、状态修改 | 可标记完成/重开 |
| Local/Export | `marketType` 区分 | 可筛选两条业务线 |
| 持久化 | JSON 文件 | 重启后数据保留 |

## 6. 非目标

当前不做：

- 自动爬取社交平台、地图、搜索引擎或联系人数据库。
- 未经授权的批量邮件、短信、微信或社交私信发送。
- 真实大模型客户评分、自动客服或 Agent 自主决策。
- 真实企业身份认证、团队权限、收费支付。
- 生产级数据库、多租户隔离、容灾和监控。
- 广告账户投放、广告预算自动优化。

## 7. 成功指标

试点阶段需要人工跟踪：首次价值时间、线索处理率、首次响应时间、有效预约率、跟进任务完成率、商机转化率、续费意愿。不能把 AI 调用量或生成文案量当作产品价值的唯一指标。
