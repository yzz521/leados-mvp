# 08 — 产品落地路线图

## 阶段 0：市场验证（先于大规模开发）

目标：明确第一款商业产品从哪个细分行业/客户群进入。

行动：

- 访谈 10 家国内本地服务商、10 家外贸工厂/贸易公司。
- 获取脱敏的真实线索表、跟进流程和现有工具使用情况。
- 验证高频痛点、当前替代方案、采购决策人和付费范围。
- 用统一评分模型比较两个方向：痛点、付费意愿、数据可接入性、合规可持续性、标准化程度。

阶段出口：确定首个产品包和 3–5 家设计合作企业。

## 阶段 1：共同底座 MVP（本压缩包）

- Local / Export 统一线索模型。
- 手工录入、CSV 导入、去重。
- 客户详情、规则评分、跟进任务、互动备注。
- 总览漏斗及基础统计。

阶段出口：真实用户能够独立导入线索、分配跟进、记录结果。

## 阶段 2：首个产品包

### Local 优先时

- 租户、登录、成员和权限。
- H5 表单、二维码、客户自有官网表单。
- 授权 Webhook / 官方渠道线索连接器。
- 可配置 AI 接待流程和知识库。
- 预约、人工转接、响应 SLA 和渠道归因。

### Export 优先时

- 国家/行业/产品 ICP 配置。
- 许可商业数据源连接器。
- 企业官网研究与来源引用。
- 联系方式验证服务。
- 个性化开发信草稿、人工审核、邮件回复同步。
- 退订/拒绝联系和国家规则引擎。

阶段出口：一条业务线完成完整闭环，并有真实留存和付费验证。

## 阶段 3：AI 与自动化

- AI Gateway、多模型、结构化输出和调用计费。
- 客户研究 Agent / AI 接待助手 / 销售跟进助手。
- 工作流触发器、条件、动作、审批、重试和日志。
- AI 评估集、抽样质检、人工反馈闭环。

阶段出口：重复工作显著减少，AI 输出可追踪、可评价、可降级。

## 阶段 4：SaaS 商业化

- 自助注册、套餐、账单、支付和发票。
- 用量中心、额度预警和超额策略。
- 多租户数据库隔离、企业权限、审计日志。
- 监控告警、备份恢复、数据删除和安全评估。
- 行业模板和连接器目录。

阶段出口：客户可自助购买、开通、配置、使用和续费。

## 推荐开发优先级

| 优先级 | 事项 | 原因 |
|---|---|---|
| P0 | 登录与真实租户隔离 | SaaS 上线的安全前置条件 |
| P0 | PostgreSQL 持久化和迁移 | 数据完整性、查询和并发 |
| P0 | 数据来源、授权、退订记录 | 合规和营销安全 |
| P1 | 首个业务线的官方/授权渠道 | 形成客户入口 |
| P1 | 统一 AI Gateway | 能力升级和成本可控 |
| P1 | 销售工作流和任务提醒 | 降低漏跟进 |
| P2 | 计费、用量、支付 | 真正 SaaS 化 |
| P2 | 第二条业务线全面接入 | 在首条业务线验证后复制 |

## 不建议提前做

- 自建大型全球买家数据库。
- 全平台爬虫和未授权自动化。
- 微服务、Kafka、复杂 Agent 编排。
- 全功能广告投放管理。
- 未验证真实用量前的无限量套餐。
