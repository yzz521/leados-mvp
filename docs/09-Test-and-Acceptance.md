## 2. 自动冒烟测试

先启动服务，再执行：

```bash
python3 scripts/smoke-test.py
```

成功时输出：

```text
PASS: health, list, create, duplicate protection, analyze, task create/update/delete, activity, lead delete
```

该脚本使用唯一邮箱创建短生命周期测试数据，并在结束时删除对应任务和线索。运行测试前需要确保目标服务是测试工作空间，而非正在使用的真实客户环境。

## 4. 已知限制

- JSON 文件仓库适合演示和单机低并发，不适合多实例部署。
- 写操作会整体重写数据文件，随着数据量增大性能会下降。
- 没有分页、复杂检索、事务和数据库唯一索引。
- 没有登录、权限、组织、用户、审计操作者等能力。
- 没有真正 AI 服务、渠道账号连接、消息发送和支付。
- 删除当前为硬删除，正式版需重新设计数据生命周期。

## 5. 生产上线前阻断项

以下未完成前不应对外开放客户注册或导入真实个人信息：

1. 认证、授权、租户隔离及越权测试。
2. TLS、限流、输入校验、CSRF/CORS 与安全头。
3. PostgreSQL 事务、迁移、唯一约束和备份恢复。
4. 隐私告知、数据来源合法性、处理依据、授权证据、退出与删除流程。
5. 对外发送的渠道许可、退订同步和频控。
6. AI 输出质量评估、人工审核、模型成本控制。
7. 监控、日志、告警、故障处理和安全测试。
